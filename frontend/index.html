How Garbleworks works

×

A CyberChef for prompt injection. You write a payload, stack operations into a recipe, and the engine fans your input out into many variants — each a differently-mutated copy designed to slip past a different filter. Then you can fire those variants at an endpoint you're authorized to test and see which ones land.

The layers

Character — homoglyphs, zero-width spaces, leetspeak, invisible Unicode tags, combining marks. Breaks exact token matching without changing how text reads.
Encoding — base64, hex, ROT13, morse, binary, URL/HTML entities. Tests whether a target decodes content before it inspects it.
Prose — POS-aware synonym swaps (spaCy + WordNet) and back-translation. Rephrases the intent so keyword filters miss it.
Structure — fenced blocks, XML tags, JSON embedding, dividers, payload splitting. Reframes where the text sits in the prompt.
Template — chat-role framing, persona wraps, instruction laundering, delimiter collisions. Probes whether a system/assistant role outranks the real system prompt.
Sampler — repeat, deterministic jitter, framing-only echoes. Fans one input into many near-copies to surface intermittent or framing-driven hits.
Language — pseudo-localization, script transliteration, localized instruction framing, and multi-language fan-out. Crosses language and script boundaries to slip past English-only filters while the model still understands the intent.
Jailbreak — named high-ASR framing techniques: bijection ciphers, Likert-judge and code-completion laundering, nested fiction, policy-puppetry authority spoofs, past-tense reformulation, and best-of-N surface search. Reframes the intent so the classifier never recognizes a request to refuse.
Carrier — indirect-injection envelopes: reference-link exfil, RAG editor notes, email wraps, write-primitive fields, memory seeds. Models the untrusted-content channels an injection rides in on, rather than wrapping the text directly.
Stego — hide the payload in zero-width, variation-selector, whitespace, or emoji carriers that survive copy-paste and render invisibly.
LLM — call a local or remote model to reword or generate fresh variants when the rule-based layers aren't enough.

Workflow

1. Click or drag an operation from the left into the recipe. 2. Tune its sliders. 3. Run to preview variants (turn on Auto for live preview). 4. Save recipes you like; load presets from the dropdown. 5. Point the Target panel at an authorized endpoint, set a hit condition, and Fire.

Shortcuts

Ctrl/⌘ + Enter run · Shift + Enter fire · / focus search · Esc close

Stay in scope
